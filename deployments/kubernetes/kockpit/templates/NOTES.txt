Kockpit is starting in namespace {{ .Release.Namespace }}. The Java applications take a minute or two:

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

{{- if .Values.console.enabled }}

Open the console:
{{- if .Values.ingress.enabled }}
  {{ include "kockpit.consoleOrigin" . }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "kockpit.component" (dict "root" . "name" "console") }} 3000:{{ .Values.console.service.port }}
  then http://localhost:3000
{{- end }}
{{- end }}

{{- if .Values.auth.local.enabled }}

Accounts: {{ if not .Values.auth.local.signupEnabled }}sign-up is closed, accounts exist already{{ else if .Values.auth.local.signupInviteRequired }}by invitation, the administrator creates the links on the console's "Tenant & API keys" page{{ else }}anyone can sign up on the console{{ end }}.
{{- if .Values.auth.local.adminEmail }}
Administrator {{ .Values.auth.local.adminEmail }}, password:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "kockpit.secretName" . }} -o jsonpath='{.data.admin-password}' | base64 -d; echo
{{- else }}
No administrator (auth.local.adminEmail): nobody can see every tenant, change a key's quota or invite the first accounts.
{{- end }}
{{- end }}

Ingestion gateway (applications send audits with a tenant's API key):
  {{ . }}/ingest/v1/audits
{{- end }}

{{- if .Values.sampleApp.enabled }}

Generate audits with the sample application:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "kockpit.component" (dict "root" . "name" "sample-app") }} 8082:8082
  curl http://localhost:8082/sample-app/api/sayHello/kockpit
  curl -X POST http://localhost:8082/sample-app/api/createMessage -H 'Content-Type: application/json' -d '{"message":"hello"}'
{{- end }}
