# WCP Rest Api filter for Content-language

This library is a Filter for content-language negotiation

Need a LocalResolver to resolve the Locale

Add the valid locale in the Request header "Content-Language" with the LocalResolver

## Include Dependency

```
    <dependency>
        <groupId>com.accor.wcp</groupId>
        <artifactId>wcp-rest-api-filter-contentlanguage</artifactId>
        <version>${wcp.bom.version}</version>
    </dependency>
```

- Can be used with library [wcp-rest-api-filter-contentlanguage]
